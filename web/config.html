⚠️ Tips Konfigurasi

  • Pastikan Mode Environment sesuai (Development untuk testing, Production untuk live)
  • Cons ID dan Cons Secret harus valid dan sesuai dengan yang diberikan BPJS
  • User Key harus sesuai dengan modul yang digunakan (VClaim User Key untuk VClaim, Antrean User Key untuk Antrean, dll)
  • Jika mendapat error "Authentication failed", periksa kembali semua kredensial
  • Pastikan tidak ada spasi di awal/akhir saat copy-paste kredensial
